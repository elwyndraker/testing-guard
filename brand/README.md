# PrivacyGuard brand

<img src="logo/icon-256.png" width="128" alt="PrivacyGuard icon">

The logo is a faceted mint shield with a keyhole, circled by an orbit ring, on a dark teal background.

Every file in this folder is generated by [`generate.py`](generate.py), and so are the app's launcher drawables. To change the logo, edit the shapes or colors in the script and run it again:

```
python3 brand/generate.py
```

It needs Python 3 with PyGObject (librsvg and pycairo) and Pillow. On Fedora: `sudo dnf install python3-gobject librsvg2 python3-cairo python3-pillow`.

## Google Play upload

| Play Console field | File | Play requirement | This file |
|---|---|---|---|
| App icon | [`play-store/icon-512.png`](play-store/icon-512.png) | 512 x 512 PNG, 32-bit, sRGB, up to 1024 KB, full square | 512 x 512, 32-bit, fully opaque, about 40 KB |
| Feature graphic | [`play-store/feature-graphic-1024x500.png`](play-store/feature-graphic-1024x500.png) | 1024 x 500 JPEG or 24-bit PNG, no transparency | 1024 x 500, 24-bit RGB, about 80 KB |

The Play icon is a plain square on purpose. Google Play rounds the corners and adds the shadow itself, so the file must not have its own rounded corners, shadow or padding. The shield and ring sit well inside the center, so nothing is cut off by the rounding.

Phone screenshots are not generated here. Use the real screenshots in [`../screenshots`](../screenshots). Play needs at least 2, between 320 px and 3840 px on each side, with the long side no more than twice the short side.

## In the app

The app's minimum is API 26, so the launcher uses an adaptive icon only (`res/mipmap-anydpi/ic_launcher.xml` and `ic_launcher_round.xml`) with three vector layers in `res/drawable`:

| Layer | File | Purpose |
|---|---|---|
| Background | `ic_launcher_background.xml` | Dark teal radial gradient |
| Foreground | `ic_launcher_foreground.xml` | Shield, keyhole and ring, inside the 66 dp safe zone of the 108 dp canvas |
| Monochrome | `ic_launcher_monochrome.xml` | Single-color silhouette for Android 13+ themed icons |

Because the layers are vectors, they stay sharp at every screen density without PNGs.

## Folder contents

| Folder | What is in it |
|---|---|
| `svg/` | Vector masters: full icon (square and round), mark only (color, white, black), the three adaptive layers, both lockups and the feature graphic |
| `play-store/` | The two Play Console uploads above |
| `android/adaptive/` | Adaptive icon layers as 432 x 432 PNGs (108 dp at xxxhdpi), for previews or other tools |
| `android/mipmap-*/` | Legacy `ic_launcher.png` and `ic_launcher_round.png` at 48, 72, 96, 144 and 192 px. The app does not need them (API 26+), but they are here for other tools that ask for them |
| `logo/` | Icon (square and round), transparent mark, white mark, and the horizontal lockup with the wordmark for dark and light backgrounds |
| `web/` | `favicon.ico`, `favicon.svg`, PNG favicons (16 to 512 px) and `apple-touch-icon.png` (180 px), for the GitHub Pages site |

The lockup SVGs use live text in the Adwaita Sans font, with Inter, Roboto, Helvetica and Arial as fallbacks. For print or other software, use the lockup PNGs, or convert the text to outlines first.

## Usage

- Leave clear space around the icon of at least a quarter of its width.
- Do not recolor, stretch, rotate, or add effects to the mark.
- On light backgrounds, use the full icon (with its dark background) or `lockup-light`, not the bare mark: the mint ring loses contrast on white.
